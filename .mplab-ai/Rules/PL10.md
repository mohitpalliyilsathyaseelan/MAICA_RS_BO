## Compiler & Toolchain
- Always target the Microchip XC32 Compiler.
- Do not use standard GCC attributes unless compatible with XC32.

## Hardware Architecture: PIC32CM PL10 CNano
- User LED (LED0) is connected to Port Pin **PB02**. 
- User Switch (SW0) is connected to Port Pin **PB03**.
- System core voltage must align with low-power rules if modifying PLIB Clocks.

## Code Style & Structure (MCC Harmony v3)
- Never directly manipulate peripheral registers if an MCC PLIB (Peripheral Library) function exists (e.g., use `GPIO_PinWrite()` instead of writing to `PORT->Group[0].OUT.reg`).
- All asynchronous driver calls must pass through standard Harmony callback patterns.
- Do not use heavy standard C library functions like `printf` inside ISRs (Interrupt Service Routines).
